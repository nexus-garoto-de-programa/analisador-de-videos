# Lições aprendidas

Toda correção do dono vira uma entrada aqui, a mais recente no topo. Antes de cada análise,
o Claude lê este arquivo inteiro.

Quando uma lição se repete ou o dono diz que vale sempre, ela vira regra em
`METODO.md` → **Regras do dono** e a entrada aqui é marcada com `→ promovida`.

Formato:

```
## AAAA-MM-DD — <pasta da análise>
- **Eu disse:** …
- **O certo é:** …
- **Regra geral:** … (o que fazer nos próximos vídeos)
```
